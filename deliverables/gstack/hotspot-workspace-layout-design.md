### 1.1 设计 token（§6.0 设计语言，frontend/src/index.css + tailwind.config.ts）

| 维度 | 值 |

### 1.2 组件模式（从 Dashboard / Regime / Hotspots 提炼）

- **卡片**：`rounded-card border border-border bg-surface/80 + backdrop-blur-sm + hover shadow`（Regime 的 `cardCls` 是全站标准卡片，Hotspots 目前用的是实心 `bg-surface`，略旧）
- **SectionTitle**：渐变竖条（h-3 w-0.5 accent→accent/30）+ 小图标 + text-xs semibold 标题 + 右侧 text-[10px] mono hint
- **页头卡片**：左侧全高渐变竖条（w-1）+ 图标 + 标题 + 副标题；右侧控件组
- **分段按钮组（pill）**：`border border-border bg-base/60 p-0.5` 容器，内部 h-6 `rounded-[5px] px-2.5` 按钮，active = `bg-accent text-white shadow-sm` —— Regime:144 起的市场切换/时间范围/视图切换全部用这个模式
- **表格**：text-[11px] 表头（muted、右对齐数字列）、行 py-1.5~2、divide-border/60 分隔、mono 数字、hover bg-elevated、选中 bg-accent/10
- **徽标（badge）**：`rounded px-1.5 py-0.5 text-[10px]` + 语义色 15% 透明度底 —— 热点阶段五色（labels.ts）、角色五色、质量五级均复用此模式
- **ScoreBar**：h-1 w-10 圆角进度条 + 右侧 mono 数值，缺失显示 '—' 不画条
- **告警条**：`border-warning/40 bg-warning/10` / `border-danger/40 bg-danger/10` + AlertTriangle 图标，text-xs

### 1.3 密度与节奏

高密度终端型界面：正文 text-xs (12px)、表格 text-[11px]、标注 text-[10px]、行高紧凑。适合 Amber（活跃交易者、表格优先、14:30-14:57 固定节奏）。

## 2. 布局变体

### 变体 A `list-first` 保守增强 —— 维持「全宽表格 + 右侧抽屉」骨架

信息层级：页头（标题 + 全局市场/top/同步）→ 元信息条 → 阶段筛选 chips 行 → 全宽 9 列表格 → 点击行开抽屉（现有 Modal 结构增强版：metrics + 时间线 sparkline + 成分股 + route/新闻占位）。

```
┌──────────────────────────────────────────────────────────────────┐
│ ▎🔥 热点工作区   [A股|港股|美股] [20|50|100] [同步]                │ ← Regime 式页头
├──────────────────────────────────────────────────────────────────┤
│ 数据源·主题数·最近同步·状态·快照·质量      (可折叠)               │ ← 元信息条
├──────────────────────────────────────────────────────────────────┤
│ [搜索____] [全部|初次异动|确认扩散|加速主升|分歧放量|降温退潮]      │ ← 新增工具行
├──────────────────────────────────────────────────────────────────┤
│ #  主题          阶段     涨跌幅   热度↗  趋势  持续  领涨股 质量 │
│ 1  人形机器人    加速主升 +4.82%  ▓▓▓82  76   64   三花…   完整 │
│ 2  固态电池      加速主升 +3.96%  ▓▓▓78  71   69   德尔…   完整 │
│ …（全宽 9 列，max-h 内滚动）                                      │
└──────────────────────────────────────────────────────────────────┘
        点击行 ──► 右侧 Modal 抽屉（现有，增强: 时间线 sparkline 图 +
                      route 链路 chips + 新闻占位）
```

交互：市场切换接 `useMarket()`；新增搜索（匹配主题/领涨股/成分股）、阶段筛选、排序；抽屉内 timeline 由列表渲染改为 SVG 折线 + 阶段色带。

- **优点**：改动最小，骨架/组件全部复用；全宽表格信息密度最高；不动用户肌肉记忆。
- **缺点**：Modal 开销仍在 —— 对比 N 个主题需要 2N 次开合；上下文遮挡问题未解决；后续加时间筛选/图表会让抽屉无限变长。
- **适用**：改动预算紧、或验证「用户主要是单向深读单主题」的场景。

### 变体 B `master-detail` 工作台（推荐）—— 常驻主从分栏

信息层级：页头（同 A）→ 元信息条（精简）→ 阶段分布条（新：五段生命周期分布 + 新晋/退潮计数）→ 主从双栏：左 = 扫描区（搜索 + 阶段 chips + 排序 + 紧凑列表），右 = 详情区（常驻，标题/指标/时间线/链路/成分股/新闻占位）。

```
┌──────────────────────────────────────────────────────────────────┐
│ ▎🔥 热点工作区  A股·30分钟同步   [A股|港股|美股] [20|50|100] [同步] │
├──────────────────────────────────────────────────────────────────┤
│ 数据源 东财概念 · 主题数 47 · 最近同步 14:32 · 快照 09-15 · 质量  │
├──────────────────────────┬───────────────────────────────────────┤
│ 阶段分布 ▓▓│▓▓▓│▓▓▓▓│▓▓▓│▓▓▓   新晋 3 │ 分歧/退潮预警 3          │
├──────────────────────────┴───────────────────────────────────────┤
│ 左·扫描区 (约42%)         │ 右·详情区 (约58%, 常驻)                │
│ [搜索主题/领涨股/代码___] │ 人形机器人 [加速主升] 持续热门  +4.82%  │
│ [全部][初次][确认][加速…] │ 样本86·成分7·快照09-15·[数据完整]      │
│ [排序: 热度|涨幅|持续]     │ ┌热度┐┌趋势┐┌持续┐┌降温┐┌领涨股┐     │
│ ┌─────────────────────┐  │ │82.4││76.0││64.5││18.2││三花…│     │
│ │1 人形机器人 加速 +4.8%│◄─┤ └────┘└────┘└────┘└────┘└─────┘     │
│ │  快照09-15·三花/拓普  │  │ 热度时间线(20日) ~~~~~~/ 阶段色带▮▮▮  │
│ │2 固态电池   加速 +4.0%│  │ 关联链路 机器人→减速器→执行器→电机    │
│ │3 创新药     加速 +3.1%│  │ 成分股表: 角色/涨幅/额/换手/量比/评分 │
│ │4 算力租赁   确认 +2.8%│  │  三花智控 [核心龙头] 涨停 +10.01% …  │
│ │ …                    │  │ 主题新闻: ▒空状态占位(待后端)▒        │
│ └─────────────────────┘  │                                       │
└──────────────────────────┴───────────────────────────────────────┘
   ↑↓ 键盘上下切换 · 点行即换右栏 · 无弹窗
```

交互模式：
- **市场切换**：接全局 `useMarket()`（Regime:144 同款 pill）；hk/us 下元信息条切「本地行业聚合」+ 出 stale 快照告警条（沿用现有逻辑）
- **下钻/联动**：点左侧行 → 右栏原地刷新（列表不消失、不滚动）；↑↓ 键盘连续切换；选中行 bg-accent/10 + 左侧 accent 竖条
- **筛选**：关键词搜索（主题/领涨股/成分股代码）+ 阶段 chips + 三档排序，作用于左列
- **时间**：左列工具行右侧显示当前快照时刻；历史快照切换（待后端）预留为快照日期下拉
- **死区处理**：时间线 = SVG 折线 + 逐日阶段色带（数据来了即点亮）；route = chips 链路图；新闻 = 显式空状态占位（「后端待接入，占位不冒充数据」）

- **优点**：对比零开销（点行即换），匹配 14:30-14:57 的多主题扫描节奏；时间线/图表有常驻空间，后续扩展不用改骨架；左列瘦身为 5 列（#/主题/阶段/涨跌幅/热度），扫描更快，详情字段不再挤表格。
- **缺点**：实现量中等（新增分栏布局组件，Modal 抽屉改造为面板）；窄屏需要降级为「列表 + 临时抽屉」；左列列数减少，全量字段浏览依赖右栏。
- **适用**：高频复盘、多主题对比、需要时间维度的长线演进（与 Amber 画像完全吻合）。

### 推荐：变体 B

理由：Amber 的核心动作是「在固定 27 分钟窗口内横向对比 N 个热点再决定执行」，Modal 抽屉是该动作的最大摩擦点；且 timeline/route/新闻三块死区的目标形态都需要常驻展示空间，变体 A 的抽屉塞不下。风险可控点：≤1100px 降级方案保持变体 A 的抽屉交互，等于同时保底。

## 5. 设计一致性要点（给实现者）

1. **市场切换**：删除局部 `useState` 与大号 `MarketTab`，改 `useMarket()` + Regime 同款 pill 组（`MARKET_ORDER`/`MARKETS[k].short`）；切换时清空 `selected`（现有行为保留）
2. **卡片样式**：从实心 `bg-surface` 升级为 Regime 的 `cardCls`（surface/80 + blur + hover shadow），与市场环境页统一
3. **阶段/角色/质量徽标**：完全复用 `labels.ts` 映射，不新造颜色；时间线色带直接用 `STAGE_CLASS` 对应底色
4. **ScoreBar**：左列热度列沿用现有 ScoreBar 组件，不重画
5. **/news 工作区关系建议**：本页「主题新闻」仅为单主题内的上下文模块（空状态占位）；`/news` 独立工作区保留为全局新闻流（跨主题检索/订阅），两者是「详情内嵌 vs 全局流」关系，不重复建设——最终以产品评审员（gstack-product-reviewer）的功能框架结论为准
6. **不做的事**：不给 timeline/route 编造假数据接口；筛选/排序全部前端本地即可（top 100 内）；mockup 仅放 deliverables，不触碰 frontend 源码
