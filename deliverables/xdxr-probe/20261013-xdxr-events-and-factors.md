# A股除权除息（GetXdxrInfoCmd）+ 自建复权因子

**日期**：2026-10-13　**提交**：`49763fb`　**结论：真源可用，偏差边界已知且随包下发。**

---

## 1. 为什么要做这件事

本地 `adj_factor` 表是空的（TickFlow `ex_factors` 对本账号返回 0 行），所以 enriched 里存的是**不复权价**，任何前复权都得现算系数。历史上一律用腾讯自己的结果——黑盒，而且回答不了"这一天为什么跌 44%"。

`GetXdxrInfoCmd`（通达信标准市 7709，vendored `easy_tdx` 里一直躺着没启用）给的是**原始权益事件**：日期、每股分红、送转比例、配股价、前后股本。这是唯一能自己复核的输入。

---

## 2. 三条实测事实（探针归档 `deliverables/xdxr-probe/`）

**① 事件是真数据，且日期口径 = 除权除息日**

茅台 45 条（2002→2026）、格力 93 条、宁德 80 条。抽样核对：

| 股票 | 除权日 | xdxr 给的 | 现实对照 |
|---|---|---|---|
| 宁德时代 | 2023-04-26 | fenhong=2.52 / song=0.8 | 每 10 股派 25.2 元转增 8 股 ✓ |
| 贵州茅台 | 2025-06-26 | fenhong=27.673 | 2024 年度分红 ✓ |

宁德那条是本轮最硬的证据：**这是唯一带送转的样本，song=0.8 落在分母、fenhong=2.52 落在分子，公式两侧都被验证到。**

**② 日期三轮交叉验证全部对齐**

用新浪 `hfq.js` 的相邻因子比做基准（详见 §3），它的因子生效日与 xdxr 的除权日**逐条同一天**；茅台/平安/招行/伊利/比亚迪的相邻因子比与 `1/r` **偏差 0.000000%**。

**③ 存在有界偏差，且已定位根因**

| 股票 | 最大偏离(占股价) | 特征 |
|---|---|---|
| 恒瑞 / 五粮液 / 茅台 / 宁德 | 0.0008% ~ 0.011% | 纯分红/转增 |
| 苏泊尔 / 海螺 / 平安 | 0.028% ~ 0.048% | 少量回购 |
| 美的 | 0.099% | 回购注销较多 |
| **格力** | **0.467%** | 注销 3.8 亿股级别的回购大户 |

**根因**：通达信给的 `category==1` 是**名义每股分红**，而交易所实际除权扣的是"回购专户股份不参与利润分配"之后的实际值。回购注销越猛，名义值与实扣值差越大。这不是算法错误，是输入数据的口径差异——所以选择如实标注，而不是想办法抹平。

## 3. 算法与校验方法

```
r = (C - fenhong + peigujia × peigu) / ((1 + songzhuangu + peigu) × C)
    C = 除权日**前一交易日**的不复权收盘价

qfq 因子[k] = ∏(除权日在 k 之后的 r)         最新一天归一到 1
hfq 因子[k] = qfq 因子[k] / qfq 因子[0]      最早一天归一到 1
```

**校验方式**（`probe_xdxr_validate.py`）：新浪 `hfq.js` 给的是累乘因子，其 `f_i / f_{i-1}` 必须等于我们的 `1/r`。逐条相等才算通过——没有"按比例配 Georges"的自由空间。

> 探针第一版（`probe_xdxr_factor.py`）曾得出 10%~30% 的偏差全是噪声：**我用了 `qfqa` 当参数名**，腾讯不认，静默返回不复权数据。改用 `qfq`/`hfq` 后正常。这个坑已写进代码注释。

## 4. 🔴 顺带的发现：腾讯 adjratio 是「等额减法」口径

比对过程中发现腾讯的前复权系数**段内不是常数**：

```
日期          raw        qfq        差
2024-06-19    1501.000   1397.537   103.463
2024-09-11    1380.000   1276.537   103.463   ← 常数
2024-11-15    1559.000   1455.537   103.463
段内 ratio 漂移 = 2.49%
```

腾讯的 `qfq ≡ raw − Σ(未来累计每股现金分红)`，是**减固定金额**；103.463 恰好等于该段之后四次分红之和。而同一复权段内 ratio 本应是常数——漂移意味着它不是纯粹的缩放因子，乘出来的"前复权价"会随原价格波动失真。

**处理**：现有 `/api/astock/adjratio` 行为**不改**（可能有外部依赖在用旧口径），只在 docstring 里写明这段实测，并指向新端点。要不要把默认口径切到乘性版，留给你定。

**fail-closed 清单**：北交所/非 A 股代码 → `bad_code`；上游 0 条记录 → `empty_events`；日K取不到 → `bars_error`；除权日落在日K首日 → 跳过并白名单上报（不用当日收盘顶替）；分红超过前收盘价 → `bad_event` 拒绝。

>日K改走腾讯而非通达信：能回 xdxr 的那批 7709 是**信息服务器**，实测对 `GetSecurityBarsCmd` 一律回 2 字节空包。副产品是好的——两条链路共用同一份日K时，唯一自由度只剩权益事件本身，比出来的差就是口径差。
