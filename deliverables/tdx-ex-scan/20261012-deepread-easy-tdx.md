## 一、四个"推翻旧结论"的实测结果（最重要的部分）

我们用**本机真实 TCP 直连 7727**（节点 `116.205.135.205`）跑了三轮，不是读代码猜的。

### 1. ✅ 港美股分钟K 的 700 根天花板 —— 已破解

旧结论：`goods_kline`（0x122E）单次最多 700 根，所以美股分钟K 只有约 1 日、港股约 3 日。

新路径：**`GetExHistoryMinuteTimeDataCmd`（0x240C）= 单日一包完整分钟**，按 `date` 循环即可任意延长。

```
--- HK 00700 按日循环 0x240C ---
  20261005:  330 根  09:30 -> 15:59   (417.20 -> 423.00)
  20261006:  330 根  09:30 -> 15:59   (427.80 -> 428.20)
  20261007:  330 根  09:30 -> 15:59   (426.00 -> 420.60)
  20261008:  330 根  09:30 -> 15:59   (422.80 -> 411.40)
  20261009:  330 根  09:30 -> 15:59   (416.80 -> 424.80)
  20261012:  330 根  09:30 -> 15:59   (429.80 -> 425.80)
  合计 1980 根   ← 单次上限原本是 700

--- US AAPL 按日循环 0x240C ---
  20261005:  390 根  21:30 -> 27:59   (332.03 -> 332.89)
  ... 5 个完整交易日各 390 根
  20261012:    1 根  21:30 (刚开盘)
  合计 1951 根
```

- 港股 **330 根/日**（09:30–15:59），美股 **390 根/日**（21:30 → 27:59，即 mod 24 后的次日 03:59，与我们已经锁定的"会话日期 + 北京时间钟点"口径完全吻合）。
- 🔥 **0x240C 自带 `avg_price`（均价）** —— 我们现在分时均价是 m1 自己合成的，上游直给更权威，可直接替换。
- ⚠️ 待验证：`volume` 语义（美股单调递增像累计值，港股首末不单调），接入时必须差分校验后再画量柱。

### 2. ✅ "逐笔成交不可用" —— 翻案，是我们喂错了协议

旧结论：EX 不支持逐笔。真相是 **0x122F 对港股恒返回 39 字节空响应**，港股要走另一条路。

| 市场 | 命令 | 实测结果 |
|---|---|---|
| 港股 00700 | **0x23FC** 当日 | ✅ `15:59 / price_int=425000 → 425.0 HKD / vol=1500 / nature=0` |
| 港股 00700 | **0x2406** 历史(20261012) | ✅ 同上 |
| 美股 AAPL | 0x122F | ✅ `21:12 / 337.79 / vol=35 / bs_flag=2`（本来就能用） |

价格换算：**`price_int / 1000 = 港元`**。适用市场：`27 香港指数 / 31 主板 / 48 创业板 / 49 基金 / 71 港股通 / 98 暗盘`（期货期权仍走 0x122F）。页大小 1800，最多 50 页（9 万条）。

### 3. ✅ 0x240D 区间K线 —— 单次 1500 根

`GetExHistoryInstrumentBarsRangeCmd(market, code, start_date, end_date)`：一次返回 **1500 根**（>700）。注意它**没有周期参数、返回的是分钟级**数据（HK 首根 2026-01-02 09:31、US 首根 22:31 = 美东开盘后 1 分钟），不是日线。

### 4. 🔴 裸连 7727 不发登录 = 全命令被断（踩坑实录）

第一轮用 `ExTdxClient.connect()` 直连成功，但随后 `get_markets` / 所有 0x23xx / 0x236A **全部 `WinError 10054`**。
原因（`ex/commands/login.py` 注释明写）：**7727 数据查询前必须先 `MacExLoginCmd`（0x2454，80B 定长 body，EX 帧 head_flag 0x01）登录，否则服务器直接断连接**。
解法：走 `MacExClient`（自带 login），或用它已登录的 `_execute` 转发 0x23xx 命令 —— 第二轮全部通过。

> 这正好解释了我们之前"EX 服务器对不支持命令直接断 TCP"的现象：很可能不是"不支持"，而是**连接复用时后续命令落在了未登录/已断开的会话上**。我们现行的「每命令独立建连 + login」依然是对的，保持现状。

## 二、项目全貌（三路并发深读的结论）

### 和我们的关系

**同源**：`NOTICE` 与 `LICENSE` 与 clong365 版逐字相同，`ex/commands/` 12 个文件、`mac/commands/` 18 个文件名一一对应，核心类 `MacClient` / `ExTdxClient` / `MacExClient` 同名。
它是在 clong365 2026-05-22 基线上又迭代 3 个月的续作（CHANGELOG 132KB，v1.20.x）。PyPI 未发布（404）。

### 它比我们 vendor 多出来的

| 模块 | 内容 |
|---|---|
| `web/` | FastAPI + Vue 前端，**62 个 `/api/v1` 端点**，Swagger |
| `backtest/` `factor/` `portfolio/` `screen/` `strategies/` | 回测引擎、19 因子、4 种组合优化器、全市场选股扫描 |
| `chanlun/` | 缠论（笔/中枢/线段/买卖点/背驰/多级别联立） |
| `indicator.py` + `MyTT.py` | 34 指标 + 约 60 个序列函数 |
| `cninfo/` `ths_web.py` `sina/` `realtime/` | 巨潮公告、同花顺概念、新浪三表、快照轮询 |
| 工程件 | `_reconnect.py` 两阶段韧性（退避重试 + 跨主机 failover + 健康分）、async 客户端 + 60s 心跳 |

### 协议侧关键实现（要抄的）

- **`ex/_hk_transaction.py`**：`HK_STOCK_MARKETS` 集合 + 0x23FC/0x2406 路由 + `price/1000` + `trade_count=0`（ex 无此字段）+ 翻页终止 `len(batch) < page_size`。
- **`mac/adjust.py`**：QFQ 本地重算兜底。根因是**通达信服务端**对 601088 这类重度除权股的深层历史页返回**负价**（QFQ close=-3.80 而 NONE=16.58），会连锁导致回撤 >100%、年化 nan、BOLL `cash/0` 崩。兜底 = 检测到坏价 → 改取 NONE 序列 → 用 XDXR 事件本地重算。
- **`mac/commands/tick_charts.py`**：不硬编码 390，而是 `(len(body) - 71 - tail) // 14` 反推条数再切分，天然防越界（我们 vendor 里修的是同一个问题，思路一致）。
- **`commands/xdxr_info.py`**：14 类除权除息/股本变迁事件（`category==1` 分红送转按每 10 股归一、11/12 扩缩股、13/14 权证、2~10 股本变动单位万股）——**自建复权因子的最原始输入**。

### Web 端工程做法（值得抄的两条）

1. **长任务 = 提交拿 `task_id` + 轮询**：`ThreadPoolExecutor(4)` + 内存 LRU 100 条，无 Celery/Redis。语义完整（pending/running/done/failed + elapsed）。
2. **可选依赖降级**：`/bars` 优先走 MAC（可复权），MAC 挂了自动回落标准协议（不可复权但可用）→ `get_mac_client_optional`。投研面板最怕"一个源挂了整页白屏"。

### 前端（Vue3 + Vite，7 个页面全是回测/策略，没有看盘页）

- ECharts 6 **按需引入**（1MB → ~400KB）。
- `KlineChart.vue` 里 trades ↔ bars 的时间对齐：必须用**完整 datetime 字符串**建 `Map<key,index>`，不能用 `slice(0,10)`，否则分钟线同日 bar 会折叠 —— 这条是踩过才知道的经验。
- 它的 UI 是"策略实验室"不是"投研工作台"：后端 60+ 行情端点前端一个没用。**这正是我们的机会空间。**

### 明确不要碰

- **全套 async 客户端**（我们是同步/线程池架构）。
- **`screen/`** 依赖本地通达信 `vipdoc` 安装目录，容器里必然失效。
- **`ths_web.py`** 正则扒 GBK HTML，页面一改全挂，且自述禁止高频/商用。
- **`sina/`** `_build_paper_code` 只按 `code.startswith("6")` 判 sh/sz，北交所必错。
- **`realtime/`** 是 3 秒级快照轮询不是推送，做实时底座不够格。
- **`offline/`** pytdx gbbq XOR 密钥法务风险（我们 vendor 时已删，继续不碰）。
